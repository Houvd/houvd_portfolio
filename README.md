# HOUVD — Portfolio

Personal portfolio of **Giuseppe Longo (Houvd)** — songwriter, music producer and creative project curator.

A single-page website showcasing artistic projects, collaborations, soundtracks and performing-arts work.

## Live site

GitHub Pages: **https://houvd.github.io/houvd_portfolio/**

> To enable it: repository **Settings → Pages → Source: `main` branch / root**.

## Run locally

It is a static site with no build step. Open `index.html` directly, or serve it locally:

```bash
# Python
python3 -m http.server 8000
# then open http://localhost:8000
```

## Project structure

```
houvd_portfolio/
├── index.html      # full site (HTML, CSS and JS in one file)
├── assets/         # images and logos
└── README.md
```

## Sections

- **About** — artist bio and vision
- **Projects** — Twin H Collective, Rinascita Flow
- **Soundtracks & Performing Arts** — film and theatre work
- **Contact** — links and email

## Tech

Plain HTML, CSS and vanilla JavaScript. No dependencies, no frameworks.
